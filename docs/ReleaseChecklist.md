# 公开发布检查

本仓库只提供已部署设备的原生管理客户端，不提供首次 Root、刷机或固件包。

## 每次公开前

- 运行 `Scripts/check_public_release.py` 与 Gitleaks，对当前源码和所有拟公开分支、标签历史检查。
- 确认主许可证、第三方来源及资源修改说明齐全，不将新的第三方文件自动归为 MIT。
- 在没有 `Config/Local.xcconfig` 的干净目录构建、测试；检查 App 与 Widget 使用同一组身份配置。
- 从 Java 源码重建并比较桥接 dex；不得只核对预编译二进制的文件名。
- 检查 Release 不含历史部署二进制、规则数据库或真实设备配置。
- 仓库已于 2026-10-28 公开并启用 GitHub Private vulnerability reporting；发布前确认该设置有效，并验证 SECURITY.md 的入口。
- App Store 分发另行完成隐私清单与签名审核；模拟器结果不等于设备写入或商店验收。

## 首次公开的历史边界

旧 U60Manager 私有仓库保留历史。FlowDeck 的首次导入需要整理为不含安装载荷与私人签名配置的干净根提交，
而非仅在后续提交中删除文件。旧私有根提交不建立公开标签或发布附件，历史备份放在源码仓库之外。
